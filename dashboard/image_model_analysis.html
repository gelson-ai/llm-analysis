Image Generation Price vs. Performance

SourceOpenRouter /api/v1/images/models BenchmarksOpenRouter media prompt benchmarks · Design Arena Valuepass rate ÷ benchmark cost

Same metric, different units. Performance here is every judged check a model passed divided by every check it attempted, pooled flat across its benchmark prompts. Price is the mean cost_usd of those same generations — not the catalogue's per-image, per-megapixel or per-token rate — so performance and price come from identical rows and are directly comparable to each other. Cost comparability caveat, measured rather than assumed: each row now records the resolution it was generated at, and resolutions are not held fixed across models — the catalogue spans roughly 768 to 2560 pixels on the long edge and cost tracks it — so a cheaper model is not necessarily cheaper at the same fidelity. The reference table below carries a resolution column for exactly that reason. Generation time is captured per row too and is shown separately from cost and quality. Design Arena scores are shown separately and never affect the value score, and no Artificial Analysis data exists for image models at all.
